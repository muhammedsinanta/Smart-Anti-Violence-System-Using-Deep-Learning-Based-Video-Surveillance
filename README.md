# Smart Anti-Violence System Using Deep Learning Based Video Surveillance

## Project Overview

A deep learning-based video surveillance system developed to detect violent activities from video input.

The system is designed to automate violence detection and reduce dependence on continuous manual monitoring.

## Technologies

- Python
- Deep Learning
- Computer Vision
- TensorFlow / Keras
- OpenCV
- NumPy
- Flask

## Project Components

- Video-based violence detection
- Deep learning model
- Prediction module
- Web application
- Video/image processing
- Database support

## Model

The project uses a trained deep learning model for violence detection.

Model file:

`violence_detector.h5`
