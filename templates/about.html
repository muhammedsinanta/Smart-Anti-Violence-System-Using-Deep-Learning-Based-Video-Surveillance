Violence Detection using Deep Learning

The Violence Detection Using Deep Learning project is designed to analyze videos and classify them as violent or non-violent using artificial intelligence. With increasing concerns about public safety and digital content moderation, this system provides an automated solution to detect violent activities in video footage.

The model is built using CNN-LSTM architecture, which combines spatial feature extraction (CNN) with temporal sequence learning (LSTM) to accurately identify patterns of violence. The system processes uploaded videos by extracting frames, preprocessing them, and passing them through a trained deep learning model for prediction.

The backend is developed using Flask, enabling seamless interaction between the model and the web-based interface, while the frontend is built using HTML, CSS, and JavaScript for an intuitive user experience. Users can upload a video, receive real-time predictions, and preview the video post-analysis.

The project has significant applications in public surveillance, law enforcement, social media monitoring, and smart security systems, helping authorities respond quickly to violent incidents. OpenCV is utilized for frame extraction and processing, while TensorFlow and Keras power the deep learning model.

The system is designed for high accuracy, making it a reliable tool for video analysis. Future enhancements may include real-time detection, dataset expansion, and improved deep learning architectures such as transformer-based models for better accuracy. By integrating AI with security, this project highlights the potential of technology-driven safety measures in modern society.
