Violence Detection using Deep Learning

Welcome to the Violence Detection System, an AI-powered solution designed to analyze videos and detect violent activities using deep learning. This system leverages CNN-LSTM models to process video frames, identifying patterns associated with violence. Simply upload a video, and our model will analyze it to determine whether it contains violent or non-violent content. This tool is useful for public safety, surveillance monitoring, and content moderation. Our web-based interface ensures a seamless experience, allowing users to preview videos after prediction. About this Project

  • Introduction

    Violence detection is an essential task in ensuring public safety, surveillance monitoring, and digital content moderation. This project utilizes deep learning techniques to analyze videos and determine whether they contain violent or non-violent activities.

  • System Workflow

    The system follows a structured workflow to process and analyze videos. First, users upload a video through a Flask-based web application. The uploaded video undergoes preprocessing, where frames are extracted and resized. These frames are then passed through a deep learning model, which predicts whether the video contains violent content.

  • Technology Stack

    This project is built using deep learning and web technologies. The core model is implemented using TensorFlow and Keras, utilizing CNN-LSTM networks for video classification. OpenCV is used for frame extraction and processing, while Flask serves as the backend framework, connecting the model to a web-based interface.

  • Applications & Future Scope

    This violence detection system has potential applications in public surveillance, law enforcement, social media content moderation, and automated monitoring systems. It can be integrated into CCTV networks to detect violent activities in real-time, helping authorities respond swiftly.
